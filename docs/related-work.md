# Related work

Nothing below has been copied into this repository. On 2026-10-30, the GitHub API
confirmed that the three GitHub projects exist and returned the licenses shown.
The descriptions come from the original brief and from each project's one-line
repository description. Their full contents have not been reviewed, and this page
must be checked before any publication.

- [robertolocatelli81-dev/pdf-signature-test-corpus](https://github.com/robertolocatelli81-dev/pdf-signature-test-corpus)
  (CC0-1.0): a synthetic signed-PDF corpus, metadata-focused. Described as excluding
  trust chains, revocation and PAdES/LTV.
- [pepo72/pdf-forensics-kit](https://github.com/pepo72/pdf-forensics-kit) (MIT):
  forensic analysis of PDFs, not a validator comparison.
- [SignerPHP/pdf-signing-qualification, issue 7](https://github.com/SignerPHP/pdf-signing-qualification/issues/7)
  (MIT): planned independent validator adapters.
- [pdf-insecurity.org](https://pdf-insecurity.org/) and the NDSS 2021 paper "Shadow
  Attacks: Hiding and Replacing Content in Signed PDFs". The kit's case C5 is written
  from the description of the Hide class on that site, with credit to the researchers.
  Author names are not listed on the pages read, and must be added from the paper
  before any publication.
  Their exploit files and the `pdf-insecurity/pdf-attacker` repository are not used,
  because no license was found for them.
