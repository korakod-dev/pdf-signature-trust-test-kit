## ลำดับภาพ

| ฉาก | กรอบชี้ที่ | กล่องข้อความ |
|---|---|---|
| เปิดเรื่อง | ไม่มี | "ลายเซ็นตรวจผ่าน" กับ "เอกสารนี้เชื่อถือได้" เป็นคนละคำถาม |
| ตารางผล | บรรทัด network route | ไฟล์ทั้งหมดเป็น PDF สังเคราะห์ ใช้ใบรับรองทดสอบที่ใช้แล้วทิ้ง และตรวจโดยไม่มีเครือข่ายออกข้างนอก |
| ตารางผล | หัวคอลัมน์ Expected | ผลที่คาดหวังของแต่ละเคสถูกกำหนดไว้ก่อนรันจริง |
| ตารางผล | หัวคอลัมน์เครื่องมือ | pyHanko, pdfsig และ EU DSS ตรวจไฟล์เดียวกัน |
| A1 | ยอดบนหน้า | เอกสารปกติ ลงนามแล้วไม่มีการแก้ไข ยอดบนหน้าคือ 1000.00 |
| A1 | ผลทั้งสาม | ทั้งสามเครื่องมือตอบ VALID |
| C4 | ยอดบนหน้า | ตอนลงนามยอดคือ 1000.00 แต่มีการแก้ไขต่อท้ายหลังลงนาม ยอดบนหน้าจึงกลายเป็น 9000.00 |
| C4 | ผลและ modification_level ของ pyHanko | pyHanko ตอบ INVALID และจัดระดับการแก้ไขนี้เป็น OTHER |
| C4 | ผลและ coverage ของ pdfsig | pdfsig ให้ลายเซ็นผ่าน แต่รายงานว่าลายเซ็นไม่ครอบคลุมทั้งไฟล์ |
| C4 | ผล, modifications และ warnings ของ DSS | DSS ให้ลายเซ็นผ่าน พร้อมรายงานการเปลี่ยนแปลงและคำเตือน |
| C4 | ผลทั้งสาม | ข้อมูลมีอยู่ในทุกเครื่องมือ แต่ถ้าอ่านแค่บรรทัดบนสุด อาจพลาดได้ |
| D1 | บรรทัด Signed by | หน้าเอกสารเขียนว่าลงนามโดย Example Other Person |
| D1 | signer_subject ทั้งสาม | แต่ชื่อในใบรับรองคือ TEST ONLY Signer ไม่ตรงกับหน้าเอกสาร |
| D1 | ผลทั้งสาม | ทั้งสามเครื่องมือตอบ VALID ซึ่งถูกต้อง เพราะลายเซ็นไม่ได้เทียบข้อความบนหน้า คนอ่านต้องดูชื่อในใบรับรองเอง |
| F3 | ยอดบนหน้า | หน้าเอกสารเขียนยอด 1000.00 |
| F3 | ค่าใน XML | แต่ XML ที่แนบเขียน 9000.00 สองค่านี้ขัดกันตั้งแต่ก่อนลงนาม |
| F3 | ผลทั้งสาม | ไม่มีอะไรแก้หลังลงนาม ทุกเครื่องมือจึงตอบ VALID ลายเซ็นยืนยันว่าไฟล์ไม่เปลี่ยน ไม่ได้ยืนยันว่าเนื้อหาถูกต้อง |
| ตารางผล | บรรทัด Cases withheld | ชุดนี้มี 20 เคส ตารางนี้แสดง 19 เคส และงดแสดง 1 เคส |
| ตารางผล | ข้อความใต้ Observations | ผลเป็นพฤติกรรมตามเวอร์ชันและการตั้งค่าที่ทดสอบ ไม่ใช่การจัดอันดับเครื่องมือ |
| ปิดท้าย | ไม่มี | ลายเซ็นตอบว่าไฟล์เปลี่ยนไหมและใครลงนาม จะเชื่อเอกสารได้หรือไม่ ต้องดูมากกว่านั้น พร้อมเวอร์ชันและขอบเขตเป็นภาษาอังกฤษ |

## สิ่งที่ไม่ควรเพิ่มในคำบรรยายหรือข้อความประกอบตอนเผยแพร่

- "เครื่องมือนี้มีช่องโหว่" หรือ "เครื่องมือนี้ตรวจผิด"
- "ดีที่สุด" หรือคำที่เปรียบเทียบอันดับ
- "สอดคล้องกับมาตรฐาน" หรือเลขข้อของมาตรฐาน
- เหตุผลที่งดแสดง 1 เคส
- "พิสูจน์ได้ว่าบันทึกผลที่คาดหวังก่อนรัน" เพราะคนดูตรวจจากคลิปไม่ได้
